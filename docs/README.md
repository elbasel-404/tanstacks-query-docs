# TanStack Query Documentation

Welcome to the TanStack Query documentation! This folder contains comprehensive tutorials and quick start guides to help you get started with TanStack Query across different frameworks.

## Directory Structure

```
docs/
├── tutorials/          # In-depth tutorials covering key concepts
│   ├── getting-started.md
```

## Tutorials

The tutorials folder contains comprehensive guides that teach core TanStack Query concepts:

- **Getting Started**: Introduction to TanStack Query, installation, and basic usage
- **Mutations Tutorial**: Learn how to create, update, and delete data
- **Query Invalidation Tutorial**: Keep your data fresh with invalidation strategies
- **Advanced Patterns**: Master advanced techniques like infinite queries, pagination, and prefetching

## Quick Starts

The quick-starts folder provides framework-specific guides to get you up and running quickly:

- **React Quick Start**: Get started with TanStack Query in React
- **Vue Quick Start**: Get started with TanStack Query in Vue
- **Angular Quick Start**: Get started with TanStack Query in Angular
- **Svelte Quick Start**: Get started with TanStack Query in Svelte
- **Solid Quick Start**: Get started with TanStack Query in Solid

## Learning Path

We recommend the following learning path:

1. Start with the **Getting Started** tutorial to understand the basics
2. Choose your framework's **Quick Start** guide to see practical examples
3. Follow the **Mutations Tutorial** to learn data modification
4. Read the **Query Invalidation Tutorial** for data freshness strategies
5. Explore **Advanced Patterns** for sophisticated use cases
